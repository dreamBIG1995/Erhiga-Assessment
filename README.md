# Sunny Farm Visitor Attraction Website

A family-friendly website for Sunny Farm, featuring information about our petting zoo, café, play park, and nature walks.

## Features

- **Home Section** – Welcome and opening times
- **About Us** – Information about Sunny Farm
- **Activities** – Petting Zoo, Café, Play Park, Farm Shop, Nature Walks
- **Contact** – Email, phone, and contact form


## Setup

1. **Local development** – Open `index.html` in your browser
2. **GitHub Pages** – Enable in repository settings:
   - Go to Settings → Pages
   - Select `main` branch as source
   - Save (your site will be live in ~1-2 minutes)

## Development

To update the site:

```bash
# Make changes to HTML/CSS
git add .
git commit -m "Update: your message"
git push origin main
```

Changes will auto-deploy to GitHub Pages.
